# Marketing Analytics Agent

An AI-powered analytics assistant that lets you chat with 
your marketing data in plain English — no SQL, no formulas needed.

## What it does
- Upload any marketing CSV or Excel file
- Ask questions in plain English
- Get instant insights + business recommendations
- Full conversation memory — ask follow-up questions

## Tech Stack
- Python + Anthropic Claude API
- Streamlit for the UI
- Pandas for data analysis
